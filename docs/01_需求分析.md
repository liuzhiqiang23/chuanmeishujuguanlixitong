# 《电影票房预测与智能推荐系统》需求分析

> 课程作业 · 第三步 ①　|　基于 movie-system 框架与新数据集（Kaggle The Movies Dataset，5000+5000 抽样）
> 题目来源：大模型对新数据集初步分析后推荐的 5 个题目中选定的第 1 个（见 `data/新数据集初步分析与选题报告.md`）

## 1. 项目背景

原"电影数据分析与推荐系统"使用 Kaggle 票房比赛子集（训练集仅 3000 条）。本次以同源但规模大得多的 **The Movies Dataset**（45,433 部合并去重）随机抽样重建数据集（train 5000 / test 5000），并在原系统框架上升级为新项目。EDA 已证实新数据集具备强预测信号：**评分人数与票房相关系数 0.79、预算 0.72、热度 0.52**，且档期、系列片、类型等维度均存在可利用的规律——"票房预测 + 智能推荐"双核心在数据上站得住。

## 2. 用户角色与使用场景

| 角色 | 场景 |
|---|---|
| 系统管理员 | 维护电影库（导入/同步新片）、查看数据大盘与 EDA 图 |
| 数据分析人员 | 查看多维统计图，使用票房预测功能评估影片商业前景 |
| 普通用户（小程序/网页） | 浏览影片、按口味获得个性化推荐 |

## 3. 功能需求（FR）

- **FR1 数据管理**：影片基础信息（类型、演职员、公司、国家、语言、关键词）的入库、更新与检索；支持从清洗后数据集批量导入。
- **FR2 探索性分析**：保留原系统 21 张 EDA 图能力，数据集更换后图表可一键重跑。
- **FR3 票房预测**：输入影片特征（预算、类型、档期、主创、热度等），输出预测票房（对数尺度还原为美元）；支持批量预测 test.csv 并导出。
- **FR4 算法对比**：内置 **≥6 种**机器学习/深度学习模型，可一键训练、横向对比（RMSE / MAE / R²），选中最佳模型服务在线预测。
- **FR5 智能推荐**：基于影片内容特征（类型/关键词/演职员/公司/国家）的相似度推荐 + 站内评分的个性化加权，融合输出。（第五步细化：MovieLens 数据已按作业要求删除，原"协同过滤"改为"内容相似为主 + 站内评分加权"，详见 `docs/03_需求规格说明书.md`）
- **FR6 可视化**：管理后台图表页、预测结果页、推荐页沿用原框架交互。

## 4. 非功能需求（NFR）

- **性能**：单次预测接口响应 < 500ms；全量 5000 条批量预测 < 60s。
- **可复现**：所有模型固定随机种子（42），同数据同结果。
- **可扩展**：新增算法只需在算法注册表中登记，不改主流程。
- **数据安全**：更换数据库前旧库完整备份；密钥类文件不入库。

## 5. 数据需求

| 数据 | 说明 |
|---|---|
| `data/train.csv` | 5000×25，含票房标签 revenue（建模主表） |
| `data/test.csv` | 5000×24，无票房（预测目标） |
| `data/processed/train_clean.csv` | 清洗+27 个派生特征后 5000×48（算法输入） |
| `data/processed/test_clean.csv` | 5000×46 |

> 原列表中的 `data/recommendation/personal/`（MovieLens 评分）已按第三步④"删除算法中电影系统相关的算法文件和数据集"一并清理，推荐策略相应改为基于新数据集的内容相似（见 `docs/03_需求规格说明书.md` FR6）。

## 6. 约束与边界

- 本阶段（第三步）只做**底层算法设计**：离线训练 + 离线评估，不接 Web 接口；在线 API（predict_api/recommend_api 适配新数据）按后续步骤再做。
- 票房建模在对数尺度（log10）上进行以对冲长尾分布；评分缺失、预算缺失等已在预处理阶段标记。
- 深度学习部分使用 scikit-learn 多层感知机（MLP），不引入额外重型框架，保证同学机器可复现。
