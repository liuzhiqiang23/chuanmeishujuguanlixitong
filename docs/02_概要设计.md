## 1. 总体架构

沿用 movie-system 框架的四层结构，替换数据与算法内核：

```
Vue3 管理后台 / 微信小程序          （展示层，沿用）
        │  HTTP

        │  ProcessBuilder / JDBC
Python 算法引擎  +  MySQL 8.0      （算法层【本次重写】 / 数据层【本次重建】）
```

## 3. 票房预测算法底座设计（第三步核心）

### 3.1 任务定义

- **任务类型**：回归。目标变量 `log10(revenue)`（EDA 证实票房长尾，对数尺度近似正态）。
- **训练数据**：`data/processed/train_clean.csv`（5000×48），按 8:2 切分训练/验证（seed=42）。
- **评估指标**：RMSE、MAE（对数尺度）、R²，另附各模型训练耗时。

### 3.2 特征设计（16 个数值/布尔特征 + 18 个独热维度，共 34 维）

| 类别 | 特征 |
|---|---|
| 预算/规模 | log_budget、has_budget(缺失指示)、runtime、cast_size |
| 市场热度 | log_popularity、log1p(vote_count)、vote_average |
| 结构属性 | n_genres、n_keywords、n_countries、n_companies、n_languages |
| 布尔 | is_collection（系列片）、is_english |
| 时间 | year、month |
| 类别独热 | main_genre（Top10）、main_country（Top6） |

缺失值策略：runtime 用中位数填充，其余数值特征缺失以 0 填充并保留指示位。

### 3.3 算法清单（8 种，含 1 种深度学习）

| # | 算法 | sklearn 实现 | 是否需要标准化 |
|---|---|---|---|
| 1 | 线性回归 | LinearRegression | 否 |
| 2 | 决策树 | DecisionTreeRegressor | 否 |
| 3 | 随机森林 | RandomForestRegressor | 否 |
| 4 | 梯度提升树 | GradientBoostingRegressor | 否 |
| 5 | K 近邻 | KNeighborsRegressor | 是 |
| 6 | 支持向量回归 | SVR (RBF) | 是 |
| 7 | **多层感知机（深度学习）** | MLPRegressor (2 隐层) | 是 |
| 8 | LightGBM（若环境可用） | lightgbm | 否 |

需要标准化的模型统一用 `Pipeline(StandardScaler → model)` 封装，保证训练/推理一致。

### 3.4 输出物

- `algorithm/boxoffice_prediction/metrics.json`：全部模型的指标汇总（含最佳模型标记）
- `algorithm/boxoffice_prediction/figures/algo_comparison.png`：RMSE / R² 对比图
- `algorithm/boxoffice_prediction/models/best_model.joblib`：最佳模型持久化

## 4. 数据库概要设计（第四步预告，≥8 张表）

新库名 `movie_analytics_db`，核心实体关系：电影 ↔(多对多) 类型/关键词/公司/国家；电影 ↔(多对多) 人员（区分 cast/crew）；用户对电影评分。

| 表 | 说明 | 表 | 说明 |
|---|---|---|---|
| t_movie | 电影主表 | t_person | 人员（导演/演员） |
| t_genre | 类型字典 | t_movie_cast | 电影-演员 |
| t_movie_genre | 电影-类型 | t_movie_crew | 电影-职员 |
| t_keyword | 关键词字典 | t_movie_keyword | 电影-关键词 |
| t_company | 制作公司 | t_movie_company | 电影-公司 |
| t_country | 国家字典 | t_movie_country | 电影-国家 |
| t_user | 用户 | t_rating | 用户评分 |
| t_prediction_log | 票房预测记录 | | |

共 **15 张表**，满足"至少 8 张"要求；DDL 见 `sql/movie_analytics_db.sql`。

## 5. 接口概要（后续步骤实现）

| 接口 | 方法 | 说明 |

## 6. 风险与对策

- **数据偏差**：train 抽样限定 revenue>0，模型学到的是"已上映有票房影片"的规律，对未上映影片外推需谨慎 → 预测结果页标注置信区间说明。
- **类别长尾**：main_genre 独热仅保留 Top10，其余归 Other。
- **环境差异**：LightGBM 缺失时自动降级为 7 种算法，不影响"≥6 种"要求。
